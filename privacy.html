Privacy Policy

Last updated: October 26, 2026

1. Introduction

YtOtomasyon Shorts Bot ("the App") is an automated tool that uploads short-form video content to YouTube via the YouTube Data API v3. This Privacy Policy explains what information we collect and how we use it.

2. Information We Collect

The App accesses only the YouTube account data necessary to upload videos on your behalf. Specifically, it uses OAuth 2.0 to obtain authorization and stores the resulting access/refresh tokens locally on your own server. We do not collect, store, or transmit your personal data to any third party.

3. Use of YouTube Data API

This App uses the YouTube Data API v3. By using this App, you also agree to the YouTube Terms of Service and Google Privacy Policy.

You can revoke the App's access to your YouTube account at any time by visiting Google Account Permissions.

4. Data Retention

OAuth tokens are stored only on your local server. No video metadata or user data is transmitted to or stored by this application's developers.

5. Security

OAuth tokens are stored with restricted file permissions on your server. We recommend keeping your server secure and rotating tokens periodically.

6. Contact

If you have questions about this policy, please open an issue on the project GitHub page.
